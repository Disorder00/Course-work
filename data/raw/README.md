# 原始数据说明

本项目使用 Kaggle 竞赛 **House Prices - Advanced Regression Techniques** 数据。

下载方式：

```bash
kaggle competitions download -c house-prices-advanced-regression-techniques -p data/raw
```

解压后请确认目录中存在：

- `data/raw/train.csv`
- `data/raw/test.csv`

如果无法使用 Kaggle CLI，也可以在竞赛页面手动下载数据，再把 `train.csv` 和 `test.csv` 放入本目录。

竞赛页面：
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques
